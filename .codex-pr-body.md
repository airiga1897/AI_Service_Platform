## Что изменено

- React/Vite собирается в отдельном Node.js build-stage.
- Production stage получает готовый `frontend/dist` и Python virtualenv.
- Node.js, npm, компилятор, заголовки и Poetry не попадают в production runtime.
- Build-time `collectstatic` удалён: static volume заполняет one-shot шаг `site_runtime`.
- Test stage сохраняет production layout и добавляет dev-зависимости.

## Зачем

Изолировать frontend toolchain от production runtime и подготовить образ к публикации через единый Nginx, оставив backend без host ports.

## Проверки

- stages `web` и `test` успешно собраны;
- в `web` отсутствуют `node` и `npm`;
- `/app/frontend/dist/index.html` присутствует в обоих образах;
- `/app/staticfiles` отсутствует в `web` до one-shot deployment step;
- в `test` доступен pytest 9.0.2;
- `git diff --check` проходит.
